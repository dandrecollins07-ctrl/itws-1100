## Summary

I built a guestbook application using PHP, MySQL, and jQuery. Users can submit a name and message through a form, which is stored in a MySQL database using prepared statements. The application displays entries dynamically and updates the page using AJAX without reloading.

The project includes both server-side and client-side logic. PHP handles database operations, while jQuery improves user experience through validation and animation. Security measures such as prepared statements and `htmlspecialchars()` are used to prevent SQL injection and XSS.
