MusicQuest

Group 4 — Nathen Pride, D'Andre Collins, Kevin Chen

An interactive music discovery web game where users explore genres, compete with friends, and find new songs without endless scrolling. Built with HTML, CSS, JavaScript, and a custom JSON song dataset.

View on GitHub

Project Plan

MusicQuest is a game-based music discovery app. Users answer prompts about their mood, energy, and preferences and the app returns a ranked playlist using a custom algorithm built on song metadata. Competitive features let users challenge friends.

Task Breakdown

  • D'Andre — Structure the song dataset as JSON with metadata (genre, artist, energy, etc.)
  • D'Andre — Build the playlist ranking algorithm based on user input
  • Kevin — Implement audio playback / speaker access
  • Kevin — Build the game environment and scoring logic
  • Nathen — Design and implement site layout
  • Nathen — Create animations and visual transitions

User Personas

Alex Brown

Age 19 · College Student · New York

About Listens to music daily, enjoys discovering new artists. Uses streaming platforms but gets frustrated by repetitive recommendations. Likes casual games and interactive apps.
Goals Compete with friends, find songs without endless scrolling, discover new genres effectively.
Pain Points Repetitive playlists, no good way to explore new genres.

Jonah Bill

Age 34 · Music Teacher · New York

About Driven by student education, seeks tools that create excitement in the classroom. Embraces technology but finds many platforms hard to connect with students through.
Goals Inspire students, stay open to new music, make music fun and engaging in class.
Pain Points Getting students to participate, lack of fun music-related tools for younger audiences.

Design Focus

The interface prioritizes usability and engagement — simple navigation, interactive elements, and clear feedback. Mockups were built in Figma and iterated based on the HCI principles covered in class: user personas, affordances, and feedback loops.
